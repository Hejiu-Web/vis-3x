# 坐标系与网格

理解坐标映射，是理解 3D 图表行为的基础。这一页讲清楚 vis-3x 怎么把数据放到空间里。

---

## 三个轴的分工

vis-3x 使用 Three.js 的标准坐标系：

```
        Y （高度 / 数值）
        │
        │
        │
        └────────── X （类目 / 横向）
       ╱
      ╱
     Z （深度 / 系列）
```

| 轴 | 方向 | 默认承担 |
|---|---|---|
| **X** | 向右 | 类目（时间、分类） |
| **Y** | 向上 | 数值（高度） |
| **Z** | 朝向观察者 | 系列并排 / 第三维 |

这个分工不是强制的。任何轴都可以通过 `type: 'value'` 变成数值轴。

---

## 类目轴 vs 数值轴

### 类目轴

只要给了 `data`，就是类目轴：

```ts
xAxis3D: { data: ['一月', '二月', '三月'] }
```

类目均匀分布在网格宽度上，**两端各留半个步长**，这样第一根和最后一根柱子都完整落在网格内部：

```
网格宽度 10，3 个类目，步长 = 3.333

位置:  -5      -1.67      1.67      5
        ├─────────┼─────────┼─────────┤
柱子:        ●         ●         ●
           一月      二月      三月
```

### 数值轴

不给 `data` 就是数值轴：

```ts
xAxis3D: { type: 'value', min: -5, max: 5 }
```

数值线性映射到网格宽度，以原点为中心：

```
min=-5           0           max=5
  ├──────────────┼──────────────┤
 -5             0              5
```

数值轴用于散点图、曲面图的坐标。

## 数值范围怎么算

Y 轴（数值轴）的范围来自所有系列的极值，然后向外取整到「好看」的刻度：

```ts
series: [{ type: 'bar3D', data: [120, 200, 150, 80] }]
// 数据范围 [0, 200]
// 最终 yAxis.domain 可能扩展为 [0, 248.4]：留出 8% 顶部空间，再取整到刻度
```

可以显式指定：

```ts
yAxis3D: { min: 0, max: 250 }
```

::: tip 为什么默认会自动扩展
如果柱子顶到网格最高处，会贴着顶边看起来像被裁掉。
留 8% 顶部空间后视觉上更舒服。

需要精确控制时显式设 `max` 即可。
:::

### 负数怎么处理

有负值时，`0` 平面会自动落在网格中间：

```ts
series: [{ type: 'bar3D', data: [-30, 50, -20, 80] }]
// yAxis.domain 自动变为 [-30, 80] 附近
// 负值柱子从 0 平面向下延伸
```

## 网格尺寸

网格是「画布」的实际尺寸，单位是世界坐标。库会根据类目数量自动推导：

```ts
// 大约的逻辑
gridWidth  = clamp(类目数 × 1.35, 8, 16)
gridHeight = clamp(gridWidth × 0.55, 4.5, 8.5)
gridDepth  = 多系列 ? clamp(系列数 × 2.6, 5, 11) : 6
```

一般不需要手动干预。但如果类目特别多（比如 30 个），可以显式放大：

```ts
// 通过系列里的坐标相关字段间接影响
// 或直接用 gridFloor.divisions 调整网格线密度
gridFloor: { divisions: 20 }
```

## 柱子宽度与间距

柱状图的宽度默认按类目步长自动计算：

```
步长 = 网格宽度 / 类目数

单系列:  柱子宽度 = 步长 × (1 - barCategoryGap)
多系列:  每个系列平分，再减去系列间间隙
```

可以显式控制：

```ts
series: [{
  type: 'bar3D',
  barWidth: 1.2,          // 世界单位（绝对值）
  // barWidth: '60%',     // 或按步长百分比
  barDepth: 1.8,          // 深度
  barGap: 0.08,           // 同系列内的间隙比例
  barCategoryGap: 0.3,    // 系列组之间的间隙比例
  data: [...],
}]
```

::: warning barWidth 太大时会重叠
显式设 `barWidth` 时库**不会**自动防止重叠。
如果类目很多（步长很小），而 `barWidth` 设得较大，柱子会互相穿插。

不确定时不要设这个字段，让库自动算。
:::

## 多系列怎么并排

多个柱状系列会自动沿 **Z 轴**错开，而不是像 2D 图表那样沿 X 轴挤在一起：

```ts
series: [
  { type: 'bar3D', name: '2024', data: [...] },
  { type: 'bar3D', name: '2025', data: [...] },
]
```

**为什么沿 Z 轴？** 这是 3D 的优势所在。沿 X 轴并排会压缩每根柱子的宽度，类目一多就挤成一团；沿 Z 轴错开则各系列在深度方向分层，从斜视角看能自然地看清对比关系。

也可以手动指定深度：

```ts
series: [
  { type: 'bar3D', name: 'A', data: [...] },
  { type: 'bar3D', name: 'B', data: [...], z: 2 },   // 显式指定深度（折线图）
]
```

## 堆叠

同名 `stack` 的系列会堆叠：

```ts
series: [
  { type: 'bar3D', name: '线上', stack: 'total', data: [120, 132, 101] },
  { type: 'bar3D', name: '线下', stack: 'total', data: [220, 182, 191] },
]
```

堆叠会让第二根柱子从第一根的顶部开始，而不是从地面。

**正值向上堆、负值向下堆**，两套独立累加：

```ts
series: [
  { type: 'bar3D', stack: 'x', data: [100, -50, 80] },
  { type: 'bar3D', stack: 'x', data: [60, -30, 40] },
  // 结果：第一类目 +160，第二类目 -80，第三类目 +120
]
```

## 非笛卡尔图表

下面的图表不使用笛卡尔坐标系，配置 `xAxis3D` 等字段对它们无效：

| 图表 | 坐标方式 |
|---|---|
| `pie3D` | 角度 + 半径 |
| `radar3D` | 极坐标，每个维度一个方向 |
| `funnel3D` | 按数值计算每层宽度 |
| `gauge3D` | 角度 |

这类图表的 `showCoordinate` 默认为 `false`，不会渲染坐标轴与网格。

::: tip 饼图等图表不需要配坐标系
```ts
{
  series: [{ type: 'pie3D', data: [...] }],
  showCoordinate: false,   // 默认就是 false，可以不写
}
```
:::
